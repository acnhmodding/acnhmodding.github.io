These are the emitter-set IDs and names from the particle archives in **Animal Crossing: New Horizons**. These effects are linked by **ELink**, which connects gameplay events, animations, and property changes to visual effects.

Both archives contain a file named `Particle.Nin_NX_NVN.ptcl`. The particle file defines the visual effects themselves; ELink defines when to play them and settings such as their position, scale, color, and attachment bone.

## ELink and SLink

ELink and SLink use the **XLink2** framework, with separate databases:

| System | Database archive | Purpose |
| --- | --- | --- |
| ELink | `ELink2/ELink2DB.szs` | Selects and configures visual effects. |
| SLink | `SLink2/SLink2DB.szs` | Selects and configures sounds. |

Each database contains **users**, such as `Player` or a furniture object. A user has named **asset call tables** that describe what to play. These can be requested by game code or triggered by an animation frame, a property value, or an always-active trigger. A call table can play an asset directly or use a container to select or combine several assets.

For visual effects, ELink's `RuntimeAssetName` connects a call table to the particle effect's internal name. The particle system creates the effect using a resource ID and an emitter-set ID. SLink handles audio through sound resources separately.

### Example: breaking an axe

The following is a shortened entry from the `Player` user in the ELink database, decoded with [xlink2](https://github.com/dt-12345/xlink2):

```text
斧破壊[0x9331bf1e] {
  Execute = Asset {
    AssetName = "斧破壊"
    RuntimeAssetName = "Axe_Break"
    EffectGroup = "3D"
    Matrix = 0x6
    Bone = "Hand_R"
    PositionX = -1.0
    PositionY = -4.0
  }
}
```

`斧破壊` means "axe destruction". This entry selects `Axe_Break`, which is emitter-set **ID 1** in `Park_Static`, and attaches it to `Hand_R` with position offsets. The full entry also contains rotation and rumble settings.

To change the particle effect selected by this entry, edit `RuntimeAssetName` in ELink. To change the appearance of the particle effect, edit its definition in the `.ptcl` file.

### Reading the link databases

[xlink2](https://github.com/dt-12345/xlink2#readme) can convert the link databases to editable text and back to binary. For ACNH, select the **`Park`** game profile.

First unpack `ELink2DB.szs` to obtain `ELink2DB.belnk`, then run:

```powershell
.\xlink.exe -i ELink2DB.belnk -o ELink2DB.txt --game Park --output-type Text
```

To convert the edited text back to binary:

```powershell
.\xlink.exe -i ELink2DB.txt -o ELink2DB.belnk --game Park --output-type Binary
```

The resulting binary must be repacked into `ELink2DB.szs` for the game to load it.
